# ADR-0008: The console replaces the inspector; one UI, two themes

- **Status:** Accepted (ticket 014, 2026-10-11). Reverses three `Not doing` lines in ticket 013 and the serving half of ADR-0007.
- **Options:** (a) console at `/app` beside the inspector at `/`, forever — what 013 and ADR-0007 chose; (b) **the console takes `/`, `src/ui/{index.html,app.js,style.css}` is deleted, `graph.html` + `graph.js` survive as the Graph view** (chosen); (c) a third plain-HTML UI merged into the inspector.
- **Context:** 013 kept the inspector deliberately ("this is a *new app alongside*, not a rewrite") and deferred taste: *"Light theme, mobile layout, i18n, keyboard shortcuts. Dark desktop first; taste later."* Two measured facts then arrived. The inspector loads Tailwind from `cdn.tailwindcss.com` (`src/ui/index.html:7`), so with no network it renders unstyled — in a local-first tool whose whole promise is that nothing leaves the machine. And the API has returned a per-hit score decomposition since R1 (`?explain=1`) that the inspector receives and discards, which is why ADR-0007 could say the string-concatenated `innerHTML` is *exactly* the reason it is thrown away. The console covers list, create, search, governance and graph (013 D4-D8), so after 014 the inspector has no view the console lacks and no user.
- **Decision:** one UI. `/` and `/app` both serve `dist/src/ui-next`; the inspector's three files are deleted in the same ticket, **as its last step**, after the console serves those views. `graph.html` stays where it is: `ci.yml` asserts the file exists in the packed tarball, and the console's Graph view frames it. Because the console is now the only UI, CI installs and builds `ui/` *before* `npm run build`, and `copy-ui.mjs` mirrors `ui/dist` into `dist/src/ui-next` best-effort — so the published tarball carries a console, while a package build on a machine that never installed the UI dev deps still succeeds and simply ships none. That asymmetry is deliberate: the failure it buys is a no-UI tarball, never a red build. Two theme token sets (dark default, warm-white light) replace 013's "no light theme": one token set with two values, not two designs.
- **Boundary of the exemption:** unchanged from ADR-0007. Root `dependencies` stays `{}`, no framework enters `src/`, and deleting `ui/` plus the `/` handover branch plus one `copy-ui` block returns the repo to its prior state — with one deliberate exception: the inspector this ADR deletes does not come back. That deletion is the only irreversible step and it is gated behind the console working.
- **Cost if wrong:** the repo loses its zero-build UI. A broken `ui/` build leaves no UI at all, and the installed package's UI now depends on a CI step a contributor can forget — the failure mode is a tarball that installs fine and serves nothing at `/`. Mitigation: the copy step stays best-effort so the package build never breaks, and `/` answers with "run npm run ui:build" instead of a blank 404.
- **Revisit if:** a second browser surface is ever proposed. Same trigger ADR-0007 named — that is the signal the zero-dependency constraint has been abandoned rather than bounded.
